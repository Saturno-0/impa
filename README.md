# IMPA — Reporte de maltrato animal

Plataforma web para reportar casos de maltrato animal, consultar el catálogo de animales en adopción y conocer los servicios disponibles. Incluye un panel de administración para gestionar animales, adopciones, reportes y servicios.

**Stack:** Next.js 15 · React 19 · TypeScript · Tailwind CSS

## Ejecutar

```bash
npm install
npm run dev
```

Abre http://localhost:3000.
